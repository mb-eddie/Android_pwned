# Contributing

Thanks for helping improve the series.

## Welcome
- Alternative exploitation paths (different tools, different approach)
- Fixes for errors or outdated commands
- Additional remediation guidance
- Frida/objection scripts that improve on existing ones

## Guidelines
1. Open an issue first for large changes.
2. Follow the structure in `templates/writeup-template.md`.
3. Only target intentionally vulnerable apps. No real-world targets.
4. Do not commit APKs, keystores, tokens, or personal data.
5. Keep scripts commented and runnable.
